# Assoli public app support pages

Public website, privacy, and deletion-request pages only. Application repositories remain private.

Published with GitHub Pages from the main branch, repository root.

| App | Website | Privacy | Account and data deletion |
| --- | --- | --- | --- |
| Jo Express / Shaheen | [Website](https://assoli99.github.io/app-support/shaheen-group/) | [Privacy](https://assoli99.github.io/app-support/shaheen-group/#privacy) | [Deletion](https://assoli99.github.io/app-support/shaheen-group/delete-account.html) |
| Al-Captain | [Website](https://assoli99.github.io/app-support/al-captain/) | [Privacy](https://assoli99.github.io/app-support/al-captain/privacy-policy.html) | [Deletion](https://assoli99.github.io/app-support/al-captain/delete-account.html) |

Submit these new URLs in Google Play Console. Previous Pages URLs are unavailable because the source repositories are private and their current GitHub plan does not support Pages.

Email links let users submit requests to the existing support inboxes. Publishing these pages does not perform deletion in the application database; support must process and honour requests under each app's published policy.
